# Review Pair 判斷規則

這份文件整理目前對
[`review-pair-decisions-*.progress.json`](/Users/ehanlin/workspace/answer-formatter/scripts/tmp/synonym-preprocessed-full-applied-top1000-round3/review-pair-decisions-top1000-round4-progress.json)
所採用的判斷原則。

它處理的是已經通過前處理、仍留在 `review` 的案例。
目標是把每組 `(correctAnswer, userAnswer)` 判成：

- `accepted`
- `rejected`

## 基本原則

### 1. 先看題目正文，再看答案字面

判斷時優先使用：

- `itemStem`
- `itemAnswer`

必要時才參考 `itemSolution` 來理解題意。

但 `itemSolution` 不應用來加入學生在作答當下看不到的額外限制。

### 2. `itemSolution` 只能輔助理解，不直接加嚴

若題目正文沒有明示限制，不能只因為解析寫得更嚴，就直接判成 `rejected`。

例子：

- `When` / `Because`
  - 若題目正文只要求填適當從屬連接詞，而沒有首字母或固定用法提示，則可因語意成立而接受。

### 3. 題目正文中的顯性提示要算進判斷

若學生在作答時看得到提示，這些提示必須納入。

包含：

- 首字母提示
- 題目明寫「請填代號」
- 空格外已經接好的後綴字
- 題目明寫答案型態

例子：

- `Good-bye` / `See you`
  - 若題目有 `(G)` 首字母提示，則 `See you` 不接受。
- `(Ａ)` / `經線`
  - 若題目明寫「請填代號」，則內容不接受。
- `富士` / `富士山`
  - 若空格外已接 `山`，則 `富士山` 會重複，不接受。
- `數` / `數詞`
  - 若空格外已接 `詞`，則 `數詞` 會重複，不接受。
- `腓尼基` / `腓尼基人`
  - 若空格外已接 `人`，則 `腓尼基人` 會重複，不接受。
- `畜牧` / `畜牧業`
  - 若空格外已接 `業`，則 `畜牧業` 會重複，不接受。
- `蒙古` / `蒙古族`
  - 若空格外已接 `族`，則 `蒙古族` 會重複，不接受。
- `兒童及少年性剝削防制` / `兒童及少年性剝削防制條例`
  - 若空格外已接 `條例`，則完整法名會重複，不接受。

### 4. 保守原則

若不能高信心說明兩者在該題情境下等價，優先判 `rejected`。

尤其是：

- 上下位概念
- 廣義詞與狹義詞
- 類別與個例
- 術語與近義日常詞

## 可接受的主要類型

### 1. 純格式或字形差異

例子：

- `I’m` / `I am`
- ` July 1` / `July 1`
- `《陶淵明集》` / `陶淵明集`
- `〈桃花源詩〉` / `桃花源詩`
- `MnO2` / `MnO_2`
- `NH3` / `NH_3`
- `台灣` / `臺灣`
- `子云亭` / `子雲亭`
- `形態` / `型態`
- `誹謗` / `毀謗`

若差異只是題號、memo 標記、前置編號符號或其他明顯雜訊，不影響答案本體，可視為等價。

書名號、篇名號等標點格式若不是題目明確要求的一部分，也可視為格式差異。

### 2. 數值等價

例子：

- `1/4` / `0.25`
- `3/4` / `0.75`
- `1/2+√3/2` / `(√3+1)/2`
- `6：8：9` / `18:24:27`

### 3. 經緯度表示法等價

若題目是在填寫經緯度，符號式與中文方向式可視為等價。

例子：

- `60°N` / `北緯60°`
- `30°W` / `西經30°`

### 4. 題目脈絡下的常見異稱或可接受異寫

例子：

- `超聲波` / `超音波`
- `靖康之禍` / `靖康之亂`
- `串聯` / `串連`
- `蒸氣機` / `蒸汽機`
- `達伽馬` / `達迦馬`
- `右側` / `右邊`
  - 若題目是在描述一般位置，而非精密術語情境，方位近義詞可視為等價。
- `九品任官` / `九品官人法`
  - 若題目是在談魏晉南北朝至隋唐的任官制度脈絡，制度簡稱與完整名稱可視為等價。
- `強核力` / `強力`
  - 若題目明確在四大基本作用力脈絡中，常見簡稱可視為等價。

### 5. 題目脈絡下的可接受簡稱

只有在題目正文仍能明確指向同一對象時才接受。

例子：

- `彰化縣` / `彰化`
- `重慶市` / `重慶`
- `澎湖群島` / `澎湖`
- `商品價格` / `價格`
- `西拉雅族` / `西拉雅`
- `古埃及` / `埃及`
  - 若題目句框已是 `＿＿文明` 這類歷史文明脈絡，則 `埃及文明` 可對應 `古埃及文明`。
- `中華民國` / `中華民國政府`
  - 若題目是在描述戰後接收、治理等歷史敘述，兩者都可指向同一政權主體。
- `九品任官` / `九品官人法`
  - 若題目已明確在講任官制度，則制度簡稱可對應較完整名稱。
- `臨安（杭州）` / `臨安`
  - 若括號內容只是地名補充說明，主名稱可單獨接受。
- `鐵路收歸國有` / `鐵路國有政策`
  - 若題目是在描述清末收回路權的政策措施，事件描述與政策名稱可視為等價。
- `人造衛星` / `氣象衛星`
  - 這類屬於較高風險案例，需看題意是否容許更具體的作答。

### 6. 題目在求解值，作答只填數值

若題目本質是在求解，使用者只填出解的數值，可接受。

例子：

- `x＝15` / `15`
- `x＝3` / `3`

### 7. 題目標記雜訊可忽略

若標準答案多出的是題目標記、題號或亂碼前綴，而不是答案本體的一部分，可接受。

例子：

- ` July 1` / `July 1`
- `❷壇` / `壇`
- `❶匿` / `匿`
- `①嘯` / `嘯`
- `① A` / `A`

### 8. 一般方位詞可依情境放寬

若題目是在描述日常位置，而不是幾何、座標、醫學解剖或其他精密術語情境，則一般方位詞可接受常見近義說法。

例子：

- `右側` / `右邊`
- `左側` / `左邊`

但若題目屬於需要精確術語的情境，仍應從嚴判定。

### 9. 括號補充說明可依情境省略

若標準答案的括號內容只是別名、今名、地名補註或補充說明，而非額外限制，則可接受只寫主名稱。

例子：

- `臨安（杭州）` / `臨安`

但若括號內容是題目要求的一部分、條件限制，或省略後會改變所指對象，則不可放寬。

### 10. 分隔符號或題名號格式可依情境忽略

若差異只在列舉分隔符號、書名號、篇名號等格式，而答案本體一致，可接受。

例子：

- `平流層、游離層` / `平流層 游離層`
- `《陶淵明集》` / `陶淵明集`
- `〈桃花源詩〉` / `桃花源詩`

### 11. 學科正式名稱可接受常見簡稱

若題目脈絡明確，正式術語可接受常見簡稱或慣用稱法。

例子：

- `高氣壓` / `高壓`
- `主語` / `主詞`
- `性別平等教育委員會` / `性別平等委員會`
- `原住民自治權` / `自治權`

### 12. 題目脈絡已明確時，可接受較具體或補足地區限定的作答

若題目正文已將場景限定清楚，較具體的補足作答可接受。

例子：

- `總督` / `台灣總督`

## 應排除的主要類型

### 1. 題目有顯性提示，但作答不符合提示

例子：

- 首字母提示：
  - `Good-bye` / `See you`
- 代號題：
  - `(Ｆ)` / `魚`
  - `(Ｄ)` / `章魚`

### 2. 空格外已有固定後綴，作答會造成重複

例子：

- `富士` / `富士山`
- `東北方` / `東北`
  - 這類要看題目是否已在空格外接了 `方`
- `甲午` / `甲午戰爭`
- `數` / `數詞`
- `腓尼基` / `腓尼基人`
- `畜牧` / `畜牧業`
- `蒙古` / `蒙古族`
- `兒童及少年性剝削防制` / `兒童及少年性剝削防制條例`

### 3. 數值不同

例子：

- `49/20` / `7/2`
- `8√5` / `140`
- `30°E` / `60°W`
- `±6` / `4`

### 4. 詞性、語法、時態不同

例子：

- `When` / `Because`
  - 若題目正文真的要求的是特定語意，則不接受
- `feel` / `are`
  - 若空格位在固定片語中，如 `feel under the weather`，則不接受替換。
- `with` / `together`
  - 若空格位在固定句型位置，僅語意接近但句法不成立者，不接受。
- `held` / `hold`
- `giving` / `gave`
- `has` / `eats`

### 5. 上下位概念不同

例子：

- `人造衛星` / `氣象衛星`
  - 是否接受要看題目脈絡
- `山地` / `高山`
  - 在地形分類題中不接受
- `股份` / `股票`
  - 在制度名詞題中不接受
- `秦國` / `秦始皇`
  - 即使同屬一段歷史脈絡，若句中要求的是國家／政權主體，不能以人物替代。

### 6. 題目要求完整答案，但作答只有部分內容

例子：

- `50°或130°` / `50`
- `(ｄ)(ｇ)` / `adfg`
- `甲、乙、丙、丁` / `乙、丙、丁`

## 目前已明確採納的補充判準

### 1. 地名簡稱可放寬，但不能無限制泛化

可以接受：

- `彰化縣` / `彰化`

不能因此直接推廣成所有：

- `X縣` / `X`
- `X國家公園` / `X`

都接受。

### 2. 歷史文明名稱可依句框放寬

若題目正文已明確限定在古代文明或歷史文明脈絡，則不一定要求學生把 `古` 字完整寫出。

可以接受：

- `古埃及` / `埃及`

但不能因此直接推廣成所有：

- `古X` / `X`

都接受，仍需看句框是否已經明確是 `＿＿文明`、`＿＿文化`、`＿＿王朝` 等歷史脈絡。

### 3. 歷史敘述中的政權主體可依句框放寬

若題目是在描述接收、治理、統治、建政等歷史敘述，國名與政府名有時都可指向同一政權主體。

可以接受：

- `中華民國` / `中華民國政府`

但不能因此直接推廣成所有：

- `國家名` / `政府名`

都接受，仍需看句框是否確實在指涉同一政權主體。

### 4. 首字母提示屬於正式限制

例子：

- 題目出現 `(G)`，則 `Good-bye` 與 `See you` 不能視為等價。

### 5. 解析不能替學生新增題目限制

若題目正文沒有顯示，不能只因解析指定某個答案就加嚴。

例子：

- `When` / `Because`
  - 若正文未限制，不能只因解析偏好 `when` 就直接排除。

### 6. 題目若在問量值變化，應接受量化描述

若題目空格要填的是「增加／減少／不變」這類量值變化，不能只因語感接近就接受其他描述。

例子：

- `增加` / `變遠`
  - 雖然都可能指向距離拉長，但題目要的是量值變化表述，故不等價。

## 使用建議

實務上複查 `progress.json` 時，建議依下列順序：

1. 先掃 `accepted` 的 `medium`
2. 再掃 `rejected` 中理由過於籠統的案例
3. 每次修正時只改精準 `id`
4. 避免用會覆蓋既有人工修正的批量補值流程
